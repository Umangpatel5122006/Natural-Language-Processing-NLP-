# Lab 5: Add-K Smoothing

## Contents

- `q1.ipynb` evaluates add-K-smoothed unigram, bigram, trigram, and quadrigram language models.
- `add_k_results.csv` stores the evaluation results.

## Run

Open `q1.ipynb` and run its cells in order. The notebook uses the tokenized corpus from Lab 1 and `K = 0.3`.
