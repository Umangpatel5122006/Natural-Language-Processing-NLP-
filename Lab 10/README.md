# Lab 10: Word Embeddings and Sentiment Analysis

## Contents

- `NLP_Lab_10.ipynb` solves Q1 preprocessing and sentence representations, Q2 word analogies, and Q3 neural-network sentiment classification.
- `NLP-Lab-Assignment-10.pdf` contains the assignment.
- `data/` contains the Amazon review CSV files and their dataset readme.

## Run

Select the repository `myenv` virtual environment as the notebook kernel. If needed, install Gensim into that environment with `.\myenv\Scripts\python.exe -m pip install gensim`.

Place `GoogleNews-vectors-negative300.bin.gz`, `glove.6B.300d.txt`, and the extracted `wiki-news-300d-1M-subword.vec` in `data/`. Open `NLP_Lab_10.ipynb` and run its cells in order. The analogy question file is downloaded from the assignment's linked source when it is missing.
