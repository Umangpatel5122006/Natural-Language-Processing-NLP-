# Lab 4: N-Gram Language Models

## Contents

- `q1.ipynb` trains and compares unigram, bigram, trigram, and quadrigram models.
- The notebook also implements add-one (Laplace) smoothing and evaluates model perplexity.
- `ngram_results.csv` stores the model results.

## Run

Open `q1.ipynb` and run its cells in order. The notebook reads the tokenized corpus from Lab 1.
