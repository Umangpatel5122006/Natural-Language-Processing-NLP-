# Lab 8: NLP Questions

## Contents

- `mid_sem_soln.ipynb` contains the five question prompts, code, calculations, and answers.
- `q2.ipynb` implements the noisy-channel spell-correction model and evaluates its accuracy.
- `NLP-Lab-Assignment-8-2026.pdf` and `NLP-Midsem-Questions-Monsoon-2026.pdf` contain the supplied question papers.
- `Spell-Correction/` contains the spell-correction data files.

## Run

Open `mid_sem_soln.ipynb` from the repository and run its cells in order. The notebook writes its question results to `outputs/`:

- `q1_fst_results.json`
- `q2_wordpiece_results.json`
- `q3_tfidf_results.json`
- `q4_naive_bayes_results.json`
- `q5_kneser_ney_results.json`
- `q2_spell_correction_results.json`
- `q2_spell_correction_predictions.csv`
