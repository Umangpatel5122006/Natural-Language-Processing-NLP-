# Natural Language Processing Labs

This repository contains coursework and experiments organized by lab. Each lab's folder contains its notebook, scripts, data, or outputs.

## Labs

| Lab | Topics | Main files and outputs |
| --- | --- | --- |
| [Lab 1](./Lab%201/) | Gujarati corpus processing: sentence and word tokenization, corpus statistics, and saved tokenized data. | [README](./Lab%201/README.md), `scripts/`, `outputs/` |
| [Lab 2](./Lab%202/) | Word segmentation with greedy and dynamic-programming approaches. | `NPL_Lab_2.ipynb`, `text_segmentation_dataset.json` |
| [Lab 3](./Lab%203/) | Finite-state methods: a DFA for simplified English words and an FST for noun morphology. | `NLP_Lab_3.ipynb`, `brown_nouns.pdf`, `output.txt` |
| [Lab 4](./Lab%204/) | Unsmoothed unigram, bigram, trigram, and quadrigram language models; evaluation and add-one (Laplace) smoothing. | `q1.ipynb`, `ngram_results.csv` |
| [Lab 5](./Lab%205/) | Add-K-smoothed n-gram language models and dev/test perplexity evaluation. | `q1.ipynb`, `add_k_results.csv` |
| [Lab 6](./Lab%206/) | N-gram language models with interpolated smoothing and perplexity evaluation. | `q1.ipynb`, `smoothing_results.csv` |

## Getting started

Open the notebook in the relevant lab folder and run its cells in order. Some notebooks depend on data or outputs generated by an earlier lab; check that lab's README and ensure its required files are available before running.
