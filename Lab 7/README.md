# Lab 7: Hindi Part-of-Speech Tagging

## Contents

- `q1.ipynb` trains a feature-based Naive Bayes tagger and an HMM, then compares Naive Bayes, forward Viterbi, backward Viterbi, and forward-backward decoding.
- `hindi-train-pos.txt`, `hindi-dev-pos.txt`, and `hindi-test-pos.txt` are the tagged data splits.
- `NLP-Lab-Assignment-7-2026.pdf` contains the assignment.

## Run

Open `q1.ipynb` from the repository and run its cells in order. The notebook uses the supplied train, dev, and test splits and saves per-tag F1 tables and comparison charts in `outputs/`.
