# Lab 3: Finite-State Methods

## Contents

- `NLP_Lab_3.ipynb` implements a deterministic finite automaton and a finite-state transducer for noun morphology.
- `brown_nouns.pdf` contains the supplied noun material.
- `output.txt` contains generated FST results.

## Run

Open the notebook and run its cells in order. The FST processes noun forms and writes its results to `output.txt`.
